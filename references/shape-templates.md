# tldraw Shape Templates

Copy-paste templates for each shape type. Pull colors and style tokens from `color-palette.md`. Wrap each in the standard shape envelope from `json-schema.md`:

```json
{
  "id": "shape:<unique>",
  "typeName": "shape",
  "type": "<type>",
  "x": 0, "y": 0,
  "rotation": 0,
  "index": "a1",
  "parentId": "page:page",
  "isLocked": false,
  "opacity": 1,
  "meta": {},
  "props": { /* paste from below */ }
}
```

---

## `geo` — Geometric shape with optional label

Most common shape. 20 geometric variants via the `geo` prop.

```json
{
  "geo": "rectangle",
  "w": 200, "h": 100,
  "color": "blue",
  "labelColor": "black",
  "fill": "solid",
  "dash": "solid",
  "size": "m",
  "font": "sans",
  "align": "middle",
  "verticalAlign": "middle",
  "growY": 0,
  "url": "",
  "scale": 1,
  "richText": {
    "type": "doc",
    "content": [{ "type": "paragraph", "content": [{ "type": "text", "text": "Label" }] }]
  }
}
```

**`geo` variants**: `rectangle`, `ellipse`, `triangle`, `diamond`, `pentagon`, `hexagon`, `octagon`, `star`, `rhombus`, `rhombus-2`, `oval`, `trapezoid`, `arrow-right`, `arrow-left`, `arrow-up`, `arrow-down`, `x-box`, `check-box`, `heart`, `cloud`.

**`align`** (horizontal text): `start`, `middle`, `end`.
**`verticalAlign`**: `start`, `middle`, `end`.

## `text` — Free-floating text

Use for labels, section titles, annotations — anything that shouldn't have a box around it.

```json
{
  "color": "black",
  "size": "m",
  "font": "sans",
  "textAlign": "start",
  "autoSize": true,
  "w": 100,
  "scale": 1,
  "richText": {
    "type": "doc",
    "content": [{ "type": "paragraph", "content": [{ "type": "text", "text": "Section Title" }] }]
  }
}
```

- `autoSize: true` → `w` auto-grows with content.
- `textAlign`: `start`, `middle`, `end`.

---

## `note` — Sticky note

Colored background, great for evidence artifacts, callouts, quotes.

```json
{
  "color": "yellow",
  "labelColor": "black",
  "size": "m",
  "font": "mono",
  "align": "start",
  "verticalAlign": "start",
  "growY": 0,
  "url": "",
  "scale": 1,
  "fontSizeAdjustment": 0,
  "textFirstEditedBy": null,
  "richText": {
    "type": "doc",
    "content": [{ "type": "paragraph", "content": [{ "type": "text", "text": "{\"event\": \"user.created\"}" }] }]
  }
}
```

- `textFirstEditedBy`: required prop (set to `null` for hand-authored notes).
- Notes are always ~200×200 in tldraw — size is controlled by the `size` token, not `w`/`h`.

## `arrow` — Connection

See `json-schema.md` for bindings (how to make an arrow stick to a shape).

```json
{
  "kind": "elbow",
  "elbowMidPoint": 0.5,
  "dash": "solid",
  "size": "m",
  "fill": "none",
  "color": "black",
  "labelColor": "black",
  "bend": 0,
  "start": { "x": 0, "y": 0 },
  "end": { "x": 200, "y": 0 },
  "arrowheadStart": "none",
  "arrowheadEnd": "arrow",
  "font": "sans",
  "richText": {
    "type": "doc",
    "content": [{ "type": "paragraph" }]
  },
  "labelPosition": 0.5,
  "scale": 1
}
```

Arrow labels use `richText` (ProseMirror format), same as geo/text/note shapes. For a labeled arrow use `{"type": "paragraph", "content": [{"type": "text", "text": "Label"}]}`. For no label, use an empty paragraph: `{"type": "paragraph"}`.

**`kind`**: only two values exist — `elbow` (right-angle, best for flowcharts) and `arc` (curved; `bend: 0` gives a straight diagonal). There is **no** `line` kind — it throws a `ValidationError` that aborts the render.
**`arrowheadStart` / `arrowheadEnd`**: `none`, `arrow`, `triangle`, `square`, `dot`, `diamond`, `pipe`, `bar`, `inverted`.
**`bend`**: positive number curves the arrow clockwise; negative counterclockwise. `0` = straight (only applies when `kind: "arc"`).
**`labelPosition`**: `0..1`, fraction along the arrow where the label sits.

## `line` — Multi-point line

Use for timelines, tree trunks, structural lines (not arrows).

```json
{
  "color": "grey",
  "dash": "solid",
  "size": "s",
  "spline": "line",
  "scale": 1,
  "points": {
    "a1": { "id": "a1", "index": "a1", "x": 0,   "y": 0 },
    "a2": { "id": "a2", "index": "a2", "x": 200, "y": 0 },
    "a3": { "id": "a3", "index": "a3", "x": 400, "y": 0 }
  }
}
```

**`spline`**: `line` (polyline) or `cubic` (smooth curve).
Points are keyed by id; each needs a unique `index` (`"a1"`, `"a2"`, ...) for order.

---

## `frame` — Labeled container

Groups other shapes visually. Shapes inside set `parentId` to the frame's id.

```json
{
  "w": 800, "h": 500,
  "name": "Backend",
  "color": "black"
}
```

The frame renders as a rectangle with its `name` as a label at the top-left. All shapes with `parentId: "shape:<frame-id>"` will be clipped and moved with it.

---

## `draw` — Freehand stroke

Rarely generated by hand — this is what tldraw produces from pen input. Included for completeness.

```json
{
  "color": "black",
  "fill": "none",
  "dash": "draw",
  "size": "m",
  "isComplete": true,
  "isClosed": false,
  "isPen": false,
  "scale": 1,
  "segments": [
    {
      "type": "free",
      "points": [
        { "x": 0, "y": 0, "z": 0.5 },
        { "x": 10, "y": 5, "z": 0.5 }
      ]
    }
  ]
}
```

## `highlight` — Highlighter stroke

Semi-transparent mark-up. Same structure as `draw`.

```json
{
  "color": "yellow",
  "size": "m",
  "isComplete": true,
  "isPen": false,
  "scale": 1,
  "scaleX": 1,
  "scaleY": 1,
  "segments": [
    {
      "type": "free",
      "points": [
        { "x": 0, "y": 0, "z": 0.5 },
        { "x": 50, "y": 0, "z": 0.5 }
      ]
    }
  ]
}
```

## SDK Equivalents (`editor.createShapes`)

In SDK mode, pass the same `props` but drop `typeName`, `schema`, etc. tldraw fills in defaults.

```ts
editor.createShapes([
  {
    id: 'shape:a' as TLShapeId,
    type: 'geo',
    x: 100, y: 100,
    props: {
      geo: 'rectangle',
      w: 200, h: 100,
      color: 'blue',
      richText: toRichText('Start'),
    },
  },
  {
    id: 'shape:b' as TLShapeId,
    type: 'geo',
    x: 500, y: 100,
    props: {
      geo: 'rectangle',
      w: 200, h: 100,
      color: 'green',
      richText: toRichText('End'),
    },
  },
  {
    id: 'shape:arrow1' as TLShapeId,
    type: 'arrow',
    props: {
      start: { x: 0, y: 0 },
      end:   { x: 0, y: 0 },
    },
  },
])

editor.createBindings([
  {
    type: 'arrow',
    fromId: 'shape:arrow1' as TLShapeId,
    toId:   'shape:a'      as TLShapeId,
    props: { terminal: 'start', normalizedAnchor: { x: 0.5, y: 0.5 }, isExact: false, isPrecise: false },
  },
  {
    type: 'arrow',
    fromId: 'shape:arrow1' as TLShapeId,
    toId:   'shape:b'      as TLShapeId,
    props: { terminal: 'end',   normalizedAnchor: { x: 0.5, y: 0.5 }, isExact: false, isPrecise: false },
  },
])
```

Use `toRichText('...')` (imported from `tldraw`) to build the rich-text structure from a plain string.
